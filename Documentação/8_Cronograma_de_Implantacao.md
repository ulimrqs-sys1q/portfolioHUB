# 8. Cronograma de Implantação (Fase 1)

| Semana | Atividades | Duração | Entregáveis |
| :--- | :--- | :--- | :--- |
| **Semana 1** | - Kick-off do projeto.<br>- Criação do repositório no GitHub.<br>- Configuração inicial (README, .gitignore, licença).<br>- Definição e criação da estrutura de branches (GitFlow). | 5 dias | - Repositório funcional.<br>- Documento de estratégia de branches. |
| **Semana 2** | - Configuração das políticas de segurança no GitHub (MFA, proteção de branch).<br>- Configuração do Dependabot e Code Scanning.<br>- Criação do plano de gestão de riscos. | 5 dias | - Relatório de configuração de segurança.<br>- Matriz de riscos preenchida. |
| **Semana 3** | - Configuração do ambiente de desenvolvimento local (VS Code, Git, extensões).<br>- Criação da documentação inicial do projeto (ADRs, plano de implantação).<br>- Treinamento da equipe no workflow de desenvolvimento. | 5 dias | - Guia de setup do ambiente local.<br>- Documentação de arquitetura versionada. |
| **Semana 4** | - Desenvolvimento de um protótipo "Hello World" para validar o fluxo de ponta a ponta (PR -> CI -> Merge).<br>- Configuração de um workflow básico de CI no GitHub Actions (linting).<br>- Revisão e ajuste do planejamento. | 5 dias | - Pull Request de exemplo validado.<br>- Workflow de CI básico operacional.<br>- Plano de projeto revisado. |
