# \### 💻 1. PortfolioHUB (Em Desenvolvimento)

# \* \*\*Descrição:\*\* Plataforma integrada à API do GitHub para consolidação automática de portfólios de desenvolvedores.

# \* \*\*Principais Desafios:\*\* Arquitetura de microsserviços, consumo assíncrono de APIs externas, mitigação de \*Rate Limit\* e modelagem de pipeline ETL.

# \* \*\*Tecnologias:\*\* Python, GraphQL, Redis, PostgreSQL e GitHub Actions.
